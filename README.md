# git_practice

This repository contains a sample React project located in the `it-company-site` directory.

## Running the site

1. Navigate to the project directory:
   ```bash
   cd it-company-site
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```

The site will be available at `http://localhost:3000`.
